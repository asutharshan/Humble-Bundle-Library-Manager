How to copy your Humble cookie

Chrome / Edge

  1. Sign in to Humble Bundle in your browser.
  2. Open Developer Tools (F12).
  3. Open Application → Storage → Cookies → https://www.humblebundle.com.
  4. Find _simpleauth_sess.
  5. Copy only the cookie's Value and paste it into the Authentication box above.

Firefox

  1. Sign in to Humble Bundle.
  2. Open Developer Tools (F12) → Storage → Cookies → Humble Bundle.
  3. Find _simpleauth_sess and copy its value.

Security: treat this cookie like a password. Never share it, post screenshots containing it, or commit it to GitHub. Humble Library Manager keeps it in memory only.
