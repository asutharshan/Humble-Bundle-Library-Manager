# Installation

Recommended:

- Windows 10/11
- Python 3.10+
- pip
- Tkinter / tcl-tk

Run:

```text
INSTALL_AND_RUN.bat
```

If Python is incomplete, repair/reinstall the normal Windows Python distribution and include:

- pip
- tcl/tk and IDLE
- Python Launcher
- Add Python to PATH

For a standalone EXE build:

```text
BUILD_EXE.bat
```
