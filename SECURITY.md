# Security Policy

Treat `_simpleauth_sess` as a password. Never commit it, upload it, paste it into an issue, or expose it in screenshots.

Generated JSON/YAML catalogues may contain authenticated or temporary source download URLs. Review/redact generated catalogues before publishing them.

Please report security issues privately to **arun@sutharshan.co.uk** rather than opening a public issue containing exploitable details or credentials.

Security fixes are primarily targeted at the latest release.
