# Development

Humble Library Manager was originally conceived and developed by **Arun Sutharshan** as a personal open-source project.

AI-assisted development tools, including ChatGPT, were used during development to support code generation, review, documentation, debugging and design exploration. Project requirements, architectural decisions, testing, acceptance of generated code and published releases remain the responsibility of the human project maintainer(s).

The project is intended to evolve through normal open-source community development. Contributors may use AI-assisted tools where appropriate, but contributors remain responsible for reviewing, testing and understanding the code they submit.
